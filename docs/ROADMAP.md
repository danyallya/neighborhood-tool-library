# Roadmap

1. Foundation — local shell, dependency lockfile and CI setup.
2. First safe domain slice — local tool planning, validation, reservation marker and deletion are implemented; real exchanges remain gated by policy.
3. Durable workflow — PostgreSQL migrations and repository tests, followed by retention, export and deletion rules.
4. Offline workflow — local writes, outbox, idempotency and conflict UX.
5. Release readiness — access control, audit, accessibility, backups, threat review and deployment.

Thin MVP estimate after foundation: 9-15 focused engineering days; excludes external approval.
